Interview me to gather all the information needed to create a complete, implementation-ready plan for the requested feature. Ask exactly one question at a time and wait for my answer before asking the next question. Whenever possible, provide a concise set of relevant choices for each question (for example, A, B, C, or D) based on the codebase, feature context, and common implementation approaches. Briefly explain each choice when the differences may not be obvious. Always allow me to provide a custom answer instead of selecting one of the suggested choices. Avoid asking open-ended questions when a useful set of choices can be inferred. If you can determine a sensible recommended option from the existing codebase or requirements, clearly indicate it as the recommended choice without automatically selecting it for me. Continue the interview until you have enough information to confidently define the feature, requirements, behavior, edge cases, affected areas of the codebase, technical approach, and implementation steps. Do not start implementing anything during the interview. When the interview is complete, summarize and organize everything discussed, then create a detailed implementation plan covering the feature overview, goals, requirements, user flow, technical approach, affected files or areas, data/model changes, API/backend changes, frontend/UI changes, validation, error handling, edge cases, testing strategy, and step-by-step implementation tasks. Create a Todo list containing the implementation tasks in a logical order so progress can be tracked. For each Todo item, identify any blockers or dependencies that must be completed or resolved before the task can begin. Reference blocking Todo items when applicable, and explicitly mark the blocker as 'None' when the task can be started independently. Order the Todo list based on these dependencies so blocked tasks appear after the tasks they depend on. Write the final plan to a Markdown file named PLAN_TITLE.md inside the .agents/plans directory, using a clear and descriptive name based on the feature. Do not implement the feature; only create the implementation plan and Todo list.
